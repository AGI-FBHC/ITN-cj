# 全量 API、对话与页面体验审计方案

日期：2026-10-18  
目标：在不把模型效果差误判为产品 Bug 的前提下，系统检查所有接口、全部主要页面、对话交互和 Lumin 工具；修复后重复测试并发布。

## 1. 审计范围

当前盘点结果：

- API 路径：**145 个**（含设置、知识库、Agent、会话、资源、学习、导图、任务、维护等）。
- 页面根：**12 个**：首页、学·练、我的成长、我的资源、个性化资源、资料库、伴学助手、全部会话、模型与接口、设置、错题本、校准；另有资源独立打开页 `study`。
- Lumin 工具：**41 个**（39 个领域工具 + 2 个任务中心工具）。
- 当前 CSS 中 8–11px 字号声明：**39 处**，其中成长/导图相关 28 处。这是本轮 UI 审查的重点。

## 2. 测试分层

### A. 真实模型 API 集成测试

真实模型只测试“接口是否能完整跑通”，不用模型文采作为通过标准。

测试环境：

- 复制真实模型配置到临时数据目录，不打印密钥。
- 专用小知识库：3 份文档、约 5,000 字、含中文、emoji、表格、代码、超长段落。
- 真实大库 `ha` 的完整导图生成已经成功一次（67 节点、39/39 文档覆盖、849 秒、261,406 tokens），后续不重复烧这次大额度。
- 所有写操作在临时库执行，结束后检查进程、任务、临时文件均被清理。

真实模型接口矩阵：

| 类别 | 接口 | 核心断言 |
|---|---|---|
| 基础对话 | `/api/chat` | 200、非空回答、错误模型返回可读错误、不产生脏会话 |
| 模型设置 | `/api/models/test`、`/api/models/diagnose` | 真实响应、超时/鉴权错误可区分、日志不泄露密钥 |
| 视觉 | `/api/models/vision-test` | 已配置视觉模型时成功；未配置时返回明确“不支持/未配置” |
| 知识库模型 | `/api/kb/build`、`/api/kb/search`、`/api/kb/organize` | 索引/检索/整理真实执行；中文、emoji、边界切片不抛 UTF-8 错误 |
| 旧 Agent | `/api/agent/ask` | 工具调用、引用、错误回传、停止 |
| 新 Agent | `/api/agent/ask-pi` | 流式事件、工具调用、资源/笔记/知识点写入、会话隔离 |
| 任务 Agent | `/api/agent/task-pi` | 任务完成/失败、产物落盘、重复请求不覆盖 |
| 学习资源 | `/api/study/lecture`、`/api/study/quiz/generate` | 结构化结果、校验、引用、失败可恢复 |
| 导图 | `/api/course/generate` | 小库真实生成、取消、失败保留旧图；大库成功记录只复核日志 |
| 联网 | `/api/websearch/test`、`/api/web/fetch` | 未配置明确报错；有配置时超时/限流/HTML 内容可读 |

每个真实模型接口至少：

1. 正常请求一次。
2. 失败或边界请求一次（空参数、模型错误、断网/超时其一）。
3. 检查 HTTP 包装、字段结构、持久化结果、UI/事件可观察性。
4. 记录耗时和 token；错误先判断是模型质量还是产品链路。

### B. 对话页问题矩阵

每个问题在真实模型下至少跑一次；可确定性复现的再补 mock 回归。

- 普通问答：资料内、资料外、不知道、引用出处。
- 多轮：追问、指代、上下文取舍、切会话后继续。
- 并发会话：A 会话运行中新建 B 会话并发送，B 不能被当成插话。
- 停止：生成中停止、工具执行中停止、审批等待中停止。
- 插话：运行中追加要求、空闲会话插话应拒绝。
- 会话树：编辑重发、分支、切回、回退、删除、重命名。
- 附件：图片、文档、粘贴图片、超大/不支持文件。
- 工具：单工具、多工具、工具失败、并发同名工具、工具参数被截断。
- 输出：Markdown、表格、代码、公式、任务清单、长回答、中文/emoji。
- 联网：关闭、自动、强制、无搜索配置、网页抓取失败。
- 资源生成：讲义、练习、测试、演示；候选预览、确认入库、拒绝入库。
- 异常：空输入、纯空格、超长输入、模型 401/429/500、停止后立刻再问。

通过标准：

- 不串会话、不丢消息、不重复发送、不假成功、不卡死。
- 停止后不继续产生模型请求。
- 工具结果与调用 ID 对应，错误可见。
- 任何 UTF-8、JSON、文件路径问题都归为产品 Bug。

### C. 全部页面与组件审查

页面：

- 首页
- 学·练
- 我的成长
- 我的资源（笔记/错题/网络资料）
- 个性化资源
- 资料库
- 伴学助手
- 全部会话
- 模型与接口
- 设置各子页
- 错题本
- 校准
- `study` 资源独立页
- 任务中心浮层、导图节点弹窗、资源弹窗、删除确认、归档/回收站

每个页面测试：

- 空数据、正常数据、长列表、超长标题、错误状态。
- 1440 / 1280 / 1024 / 768 / 390 五种宽度。
- 浅色、深色、系统主题跟随。
- 页面无横向溢出；滚动只出现在该出现的区域。
- 弹窗不越界、不被裁切、焦点可返回。
- 加载、空态、失败态都有下一步动作。
- 左右面板底部尽量齐平；长列表使用内部滚动。

自动化硬门槛：

- **可见文字不得小于 12px**；正文目标 13–14px，按钮目标 13–14px。
- 正文对比度 ≥ 4.5:1；大字和图形 ≥ 3:1。
- 图标按钮必须有 `aria-label` 或 `title`。
- 检测裁切、重叠、不可见焦点、页面级横向滚动。
- 截图逐页人工复核，不能只看 DOM 检测。

### D. “AI 味”与官方感审查

不把“设计不好看”当纯主观，以下作为可执行规则：

1. 细碎小字：所有 <12px 可见文字列清单并修复。
2. 英文大写眉题：统计 `LEARNING JOURNEY`、`MAP PROGRESS` 等装饰性标签，非必要则移除。
3. 卡片套卡片：识别同一页面超过 2 层的卡面嵌套。
4. 重复解释：同一页面重复说明“只统计…”“真实学习…”超过一次即合并。
5. 装饰性渐变/光环/徽章：逐页检查是否抢过主内容；无功能意义的删除。
6. 按钮文案：
   - 优先动词/名词，2–6 个汉字。
   - 禁止整句、逗号、问号、解释性括号。
   - 例：`根据当前资料生成一份完整导图` → `生成导图`；
     `去看看这条学习记录` → `查看`；
     `把这份资源加入我的学习资源` → `收录`。
7. 页面文案：
   - 先动作，后解释；同一屏最多一段说明。
   - 错误信息只保留“原因 + 下一步”。
8. 视觉一致性：
   - 按钮高度、圆角、边框、留白统一。
   - 主按钮每屏最多一个。
   - 中英文混排、全角/半角标点统一。

## 3. 问题分级与修复顺序

- **P0 阻断**：接口 500、无效 UTF-8/JSON、会话串线、数据丢失、任务卡死、停止失效。
- **P1 明显体验问题**：页面溢出、弹窗裁切、长列表拖页、按钮无响应、错误不可读、功能状态不一致。
- **P2 视觉与文案**：小字、低对比、AI 味标签、句子按钮、重复说明、卡片堆叠。
- **P3 打磨**：间距、图标一致性、次要动效、文案统一。

修复顺序固定为 P0 → P1 → P2 → P3。每个 P0/P1 修复必须增加可复现测试。

## 4. 执行阶段

### 阶段 0：基线盘点

- 生成 API、页面、按钮、小字、已有测试覆盖清单。
- 输出当前基线问题表。

### 阶段 1：真实模型 API

- 小库真实模型跑通所有模型类接口。
- 记录 token、耗时、错误分类。
- 有失败先修产品链路，再重新跑该接口。

### 阶段 2：对话压力矩阵

- 按第 B 节逐项测试，重点复现并发会话、停止、插话、工具失败和超长上下文。

### 阶段 3：页面全量审计

- 自动检查 + 五档宽度 + 深浅色 + 长数据截图。
- 人工逐页看布局、层级、文案、按钮和空态。

### 阶段 4：修复与回归

- 按 P0→P3 修复。
- 每一类修复后先跑对应专项，再跑全量回归。
- UI 改动同步检查 Lumin 是否有等价读取/执行工具。

### 阶段 5：发布验收

- 核心单测、专项检查、全量回归、真实模型冒烟、打包资产哈希、隔离启动冒烟全部通过后才发布。
- 输出最终问题关闭表：问题、证据、修复提交、复测结果。

## 6. 验收门槛

- 真实模型接口无非预期 5xx；无 `Invalid utf8 byte sequence`、无 JSON 截断崩溃。
- P0 全部关闭；P1 全部关闭或有明确延期理由。
- 所有可见文字 ≥12px；按钮无整句。
- 所有页面 1440/1024/390 无横向溢出，长列表内部滚动。
- 对话并发、停止、插话、切会话、工具失败均通过。
- 全量回归 + 打包冒烟通过。

## 7. 预计 token 与风险

- 真实模型矩阵使用小库、短输出；预计比上次真实大库导图省一个数量级。
- 不使用真实大库重复生成导图；沿用已成功的大库记录做回归证据。
- 模型质量差、拒答、幻觉只记录，不算产品功能失败；但错误未展示、状态错、数据损坏必须修。
