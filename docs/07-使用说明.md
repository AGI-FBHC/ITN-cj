# ITN-Desktop 使用说明

## 这是什么

一个在本地运行的教培内容工作台。你把自己手头的资料（Markdown、纯文本）交给它，再配上你自己的模型接口，它就能基于你的资料回答问题、生成讲义和练习题，并且每处结论都标出出处。

不需要注册、不需要登录，资料只发给你自己配置的模型服务。

## 运行环境

Windows 10 / 11，64 位。

**不需要安装仓颉，也不需要安装 Node。** 解压后直接运行即可。

## 快速开始

1. 解压本压缩包到任意目录（不要在压缩包里直接运行）。
2. 双击 `ITN-Desktop.exe`。窗口打开后，右上角显示「内核已连接」即表示就绪。
3. 进入「设置」，填写你的模型接口：
   - **Base URL**：例如 `https://api.deepseek.com/v1`
   - **API Key**：你自己申请的服务密钥
   - **对话模型**：例如 `deepseek-chat`
   - 如果服务商支持图片理解，填上**多模态模型**；如果支持向量化，填上**向量模型**
   - 点「保存模型」，再点该行的「测试」，显示「连通」即配置正确
4. 在「设置」页底部把三种用途分别绑定到刚配置的模型：
   - 对话 → 负责问答与写作
   - 向量 → 负责知识库检索（需要服务商提供 `/embeddings` 接口）
   - 切片与图片描述 → 负责把资料切块、为图片生成描述（需要多模态模型）
5. 进入「知识库」，填写：
   - 标识（随便起，例如 `course`）
   - 显示名称
   - 目录绝对路径（你放资料的文件夹）
   点「保存」，再点「建立索引」。首次建立索引会逐块调用模型，资料多时需要等待。
6. 进入「对话与产物」，选择知识库，在输入框写下问题，点「提问」。答案下方会列出出处。
   输入一个主题后点「生成讲义」或「生成练习」，产物会写入本机，界面下方「已生成的产物」里能看到文件路径。
7. 「会话记录」里可以展开每条会话，看到当时的完整事件序列——这是「答案可溯源」的实现方式。

## 数据放在哪

默认在 `%LOCALAPPDATA%\ITN-Desktop`：

| 目录 | 内容 |
| --- | --- |
| `settings.json` | 模型配置与知识库列表（含密钥，只在本机） |
| `kb\<知识库标识>\` | 索引，`index.json` 是元数据，`vectors.txt` 是向量 |
| `sessions\` | 会话日志，每会话一个 JSONL，只追加不修改 |
| `artifacts\` | 生成的讲义与练习，Markdown 格式 |

## 常见问题

**点「测试」提示连接失败。** 检查 Base URL 是否以 `/v1` 结尾、密钥是否正确、该服务是否与当前网络互通。设置页有「诊断」能力对应的接口 `/api/models/diagnose`，可自动尝试多种 TLS 协商参数并报告哪种可用。

**建立索引失败，提示 404。** 多半是服务商没有 `/embeddings` 接口。向量用途需要单独绑定一个支持向量化的服务，对话与向量可以用不同的服务商。

**图片没有被理解。** 需要在「设置」里为该模型填写多模态模型名，否则只按正文文本切片。

**回答里没有出处编号。** 说明检索没有命中内容，或对话模型没有遵循提示词。先确认知识库已经建立索引（看知识库页面的统计），再换一种更具体的问法。

**资料会上传到别处吗。** 只有你主动提问或建立索引时，相关的文本片段（以及图片）会发给你在设置里填写的那个模型服务。除此之外没有任何外部通信。
