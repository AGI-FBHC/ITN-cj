# ITN-Desktop 使用说明

## 这是什么

一个在你电脑上本地运行的教培内容工作台。你把自己手头的资料（Markdown、纯文本，含图片的也能读）交给它，再配上你自己的模型接口，它就能：

- 就你的资料回答问题，**每个结论都标出处编号**；
- 把一章内容生成**讲义**（先拟大纲，再逐节写作，最后跑一次引用自检）；
- 生成**分层练习题**与**交互式单选题**；
- 在对话里自己调用本地工具（检索资料、按 id 取原文、算数、看时间、写笔记、写产物）。

不需要注册、不需要登录，资料只发给你自己配置的模型服务。

## 运行环境

Windows 10 / 11，64 位。

**不需要安装仓颉，也不需要安装 Node。** 解压后直接运行即可。

## 界面长什么样

左边一列是功能导航（学习 / 内容 / 助手 / 系统四组，共 11 页）；进入「伴学助手」后会多出一列**会话栏**，右边是**主对话框**：上面是消息流（含工具调用步骤与出处列表），下面是输入区。

- 消息流里的每一条灰色横条都是一次真实的工具调用（例如「检索知识库 · 命中 6 个切片」）。
- 回答生成过程中会**流式显示**文字；生成期间窗口不会卡住，可以切到别的页面看。
- 会话栏里每一条都是一个可回看的会话，点开即还原当时的对话与出处。
- **按页播放**：讲义、练习册、整章资料都能翻页讲授（「我的资源」每份产物上的「播放」，或「学 · 练」章节里的「按节播放」）。播放器支持上下页、目录跳页、字号放大（讲课时后排看得清）、全屏，以及键盘 `← →`（翻页）、空格（下一页）、`T`（目录）、`Esc`（关闭）；**上一次讲到第几页会记在本机**，下次打开自动续播。
- **画像校准**（「画像校准」页）：六维能力各选一个档位（刚起步 20 / 能跟做 35 / 能独立 50 / 能带人 65 / 能设计 80），页面同时给出你在这个知识库里的真实答题正确率作对照；保存后立刻写回本机档案，也可以一键生成一条「校准记录」笔记，之后回看当时是怎么判断的。

## 快速开始

1. 解压本压缩包到任意目录（不要在压缩包里直接运行）。
2. 双击 `ITN-Desktop.exe`。窗口左下角显示「内核已连接」即表示就绪。
3. 首页「开始使用」有一张五步清单，每一步都能直接点过去；走完这五步就能出讲义了。
4. **配模型**（「模型与接口」页）：点一下预设按钮就会把地址和模型名填好，你只需要补 API Key。
   - `MiMo TokenPlan · v2.6 flash`：`https://token-plan-cn.xiaomimimo.com/v1`，对话模型 `mimo-v2.6-flash`，多模态 `mimo-v2.6-pro`。日常问答用它，便宜且快。
   - `MiMo TokenPlan · v2.6 pro`：全部用 `mimo-v2.6-pro`，理解更稳、讲义更完整，单次耗时也更长。
   - `DeepSeek` / `其它 OpenAI 兼容服务`：任何兼容 `/chat/completions` 的服务都能用。
   - 保存后点该行的「测试连通」，显示「连通 ✓」即配置正确。
   - 用途可以分开绑：`对话与生成`（问答、讲义、练习）、`向量检索`（可选）、`切片与图片描述`（多模态）。
5. **配知识库**（「档案与知识库」页）：填标识（英文短名，例如 `course`）、显示名称、资料目录的绝对路径，点「保存并建立索引」。资料多时需要等一会儿，过程中会显示实时耗时。
6. **开始用**：
   - 对话：在「伴学助手」里直接提问。想让它算数、看有哪些文档、查时间，直接说就行——它会自己调工具。
   - 讲义 / 练习册：在「学 · 练」选一章点「生成讲义」或「生成练习册」；产物是本地 Markdown 文件，在「我的资源」里能读全文。
   - 自测：在「学 · 练」点「出题练习」做单选，答错的会进「错题本」。
7. **看过程**（「会话记录」页）：每条会话都能展开成事件序列——检索了几次、调用了什么工具、模型调用了几轮、引用自检的结果。这是「答案可溯源、产物可复现」的落地方式。

## 数据放在哪

默认在 `%LOCALAPPDATA%\ITN-Desktop`，全部数据都在**一个 SQLite 文件**里（`itn.db`），可以整体拷走或备份。

| 位置 | 内容 |
| --- | --- |
| `itn.db` | 模型配置（含密钥，只在本机）、知识库登记、切片、向量、学习进度、笔记、错题、会话事件 |
| `artifacts\` | 生成的讲义与练习册，Markdown 格式 |
| `sessions\`（历史遗留） | 早期版本的 JSONL 会话日志，迁移后保留为 `*.migrated` |

## 常见问题

**点「测试连通」失败。** 检查 Base URL 是否以 `/v1` 结尾、密钥是否正确。模型行上还有「诊断连接」，会逐个尝试常见的 TLS 协商参数并报告哪一种可用。

**建立索引时提示服务没有 `/embeddings`。** 很多服务只提供对话接口（例如 MiMo TokenPlan）。这时把「向量检索」留空即可——知识库会自动退回**关键词检索**，功能不受影响；想要向量检索，单独绑一个带 `/embeddings` 的服务。

**图片没有被理解。** 需要把「切片与图片描述」绑定到一个**多模态**模型（例如 `mimo-v2.6-pro`），否则只按正文文本切片。

**回答里没有出处编号。** 说明检索没命中，或对话模型没按要求标注。先确认知识库已建立索引（「领域知识库」页有统计），再换一个更贴近资料原文的问法。

**生成讲义很慢。** 讲义是「检索 → 拟大纲 → 逐节写作 → 引用自检 → 落盘」，会多次调用模型。用 `mimo-v2.6-flash` 会明显快于 `pro`。

**资料会上传到别处吗。** 只有你主动提问、建立索引或生成内容时，相关文本片段（以及图片）会发给你在设置里填写的那个模型服务。除此之外没有任何外部通信。
