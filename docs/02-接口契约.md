# 仓颉内核接口契约（草案，未确认）

外壳与内核之间的唯一通道。所有接口只监听 `127.0.0.1`，端口由内核启动时打印到标准输出。

## 健康与元信息

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/health` | 内核存活与版本 |
| GET | `/settings` | 读取本地配置 |

## 模型配置

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/models` | 模型配置列表 |
| POST | `/models` | 新增（名称、base URL、API Key、模型 ID、能力标签） |
| PUT | `/models/{id}` | 修改 |
| DELETE | `/models/{id}` | 删除 |
| POST | `/models/{id}/test` | 连通性测试 |
| PUT | `/models/roles` | 按用途绑定：切片模型、向量模型、对话模型 |

## 知识库

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/knowledge-bases` | 知识库列表 |
| POST | `/knowledge-bases` | 指定本地目录新建 |
| POST | `/knowledge-bases/{id}/index` | 建立索引，SSE 返回进度 |
| GET | `/knowledge-bases/{id}/stats` | 文档数、切片数、图片数 |
| GET | `/knowledge-bases/{id}/documents` | 文档列表 |

## 对话与生成

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/chat` | 检索增强问答，SSE 流式返回正文与引用 |
| POST | `/generate/lecture` | 生成讲义，产出 Markdown 文件路径 |
| POST | `/generate/quiz` | 生成分层练习，产出 Markdown 文件路径 |
| GET | `/artifacts` | 已生成产物列表 |

## 约定

- 统一 OpenAI 兼容格式：`/v1/chat/completions`、`/v1/embeddings`。
- API Key 只存在本地配置文件，不出现在日志和接口响应里。
- 错误返回 `{code, message}`，`code` 为 0 表示成功。
