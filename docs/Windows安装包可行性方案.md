# Lumin Windows 安装包可行性方案

日期：2026-10-20。范围：方案与临时压缩测量，尚未构建、安装或发布正式安装包。用户刚编辑的 V1.1 项目说明不修改。

## 结论

建议将当前已验证的 Lumin 0.8.28 完整目录封装为 Windows x64 离线 EXE 安装程序，优先使用 NSIS。保留 ZIP 便携版，下载页主推安装版。

当前实现是 Electron 外壳拉起随包仓颉内核，并携带 Node 生产依赖与 PPT Python 运行组件。现有目录已经自包含，安装器可以直接部署这一目录，不必改变业务内核或要求目标电脑安装 SDK、Node 或 Python。

## 当前包与体积实测

版本以 shell/package.json 和 dist/Lumin-0.8.28/release.json 为准：0.8.28，原始功能构建提交 7b3e49c437cead6915976b76f03ea37c4c4bcf66。现有发布清单的33项资产哈希均匹配。

| 项目 | 字节 | MiB |
| --- | ---: | ---: |
| 完整程序目录 2734个文件 | 556433419 | 530.66 |
| 当前ZIP | 231932690 | 221.19 |
| 相同目录的7z临时高压缩样本 | 152744104 | 145.67 |

压缩样本使用已有7za、LZMA2、级别7、solid、2线程，不删除文件。相对当前ZIP减少79188586字节，约75.52 MiB、34.14%。样本只写到系统TEMP，未覆盖现有程序目录或ZIP。

这证明现有文件仍有较大压缩空间，不代表正式安装EXE已经生成或具有精确相同体积。NSIS原生LZMA与本次LZMA2样本的算法、字典及文件排序可能不同，最终必须构建比较。安装后文件仍约531 MiB；安装过程还需下载文件和临时解压空间。

## 建议的安装行为

- 文件名采用 Lumin-Setup-0.8.28-x64.exe，使用 Lumin 名称、图标与中文安装界面。
- 默认按当前用户安装，目录为 %LOCALAPPDATA%\Programs\Lumin，支持选择可写目录。无需常规管理员权限；用户选择系统受保护目录的情形需单独处理。
- 创建开始菜单入口，桌面快捷方式可选，安装结束可启动应用；写入当前用户的Windows卸载信息。
- 沿用 %LOCALAPPDATA%\Lumin 数据目录及现有旧目录迁移逻辑。安装目录与学习数据分开，覆盖安装保留知识库、会话、模型配置和学习记录；卸载默认保留用户数据。
- 升级前检测应用是否运行，提示正常退出，避免覆盖占用文件或强杀会话。使用稳定的安装标识，后续版本识别同一产品。
- 第一版维持现有 resources/app 与 resources/kernel 目录，保持Python子进程、资源定位和内核加载路径；不同时引入ASAR重组。
- 当前 Lumin.exe 的Windows签名状态是 NotSigned。生成安装器不会自动解决发布者信任问题，正式分发时应分别安排安装器/程序的签名策略，不宣称安装版天然免提示。

## 下载页调整

现有 tools/serve-release.cjs 的目录扫描、版本识别与文件响应只接受ZIP，必须同时改造，不能仅上传EXE。

- 服务端按明确的产品文件规则支持EXE安装包和ZIP便携包，分别设置内容类型，继续支持HEAD与Range。
- 同一版本归为一组，安装包作为主下载，便携版作为次入口，避免两个产物影响最新版本判定。
- 页面同步修改格式、体积、首次使用步骤及FAQ；保留原ZIP链接，用户V1.1说明中的直链继续有效。
- 仅在本地验收后发布到现有113.249.102.41:6025服务器，核对远端文件SHA256与公网下载，保留旧产物用于回退。

## 实施与验收顺序

1. 锁定现有已验证程序目录，保存manifest与SHA256；生成NSIS构建脚本和可复跑入口。
2. 构建首个完整安装包，核对最终EXE大小与压缩参数；若瘦身收益偏小，再比较压缩参数，不先删业务依赖。
3. 使用隔离Windows用户数据及安装目录，检查安装、快捷方式、首次配置、内核启动、已有资料读取、PDF/PPT预览和PPT输出。不得借测试修改真实用户数据库。
4. 检查重复安装、覆盖升级、运行中升级拦截、中文/空格路径、卸载和重装后数据保留；检查lumin深链接仍指向有效程序。
5. 扩展下载服务后检查安装版/便携版选择、页面文案、HEAD、Range、公网完整下载和SHA256一致性，完成后本地Git提交并追加同一TRACE。

第一版不采用联网小安装器。它只是把运行组件转移到安装阶段下载，总下载量未必减少，还会增加网络依赖。自动更新可以在安装与升级路径稳定后另行设计。
