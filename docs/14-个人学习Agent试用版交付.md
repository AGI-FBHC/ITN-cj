# 个人学习 Agent 试用版 0.2.0

日期：2026-10-15。用户要求优先交付可试用产品形态，停止扩大深度测试。

## 启动

在仓库根目录双击 `启动ITN-Desktop.cmd`，或运行 `dist/ITN-Desktop-0.2.0/ITN-Desktop.exe`。压缩包解压后可直接运行，无需安装仓颉或 Node。设置 → 关于显示版本、构建提交及数据目录。

## 本轮任务清单

- [x] 复用现有知识库检索、文档/切片读取、联网、笔记和本地文件工具。
- [x] lumin 保存完整消息及工具结果，去掉四轮文字限制；独立任务状态、停止与中断恢复。
- [x] 四类结构化资源封装为工具，由 lumin 按需选择，普通问答不自动生成。
- [x] 默认 Agent 工作台：左会话、中任务、右学习成果；学习中心保留阅读、成长、笔记与错题。
- [x] 资源稳定 id、版本、修改差异、来源切片快照；讲义阅读、实操展开、测试作答、演示精确分页与续播。
- [x] 服务端核验答案，首次作答幂等计入知识点证据；资源重开恢复反馈，重复练习不增加首次样本。
- [x] 学习偏好/目标记忆带用户原话，可编辑、忘记或关闭自动积累；新生成保存实际上下文快照。
- [x] 历史 Markdown 首次登记为 legacy，原文件保留，不补造来源、题目结构或生成画像。
- [x] 固定试用版入口、版本和包内文件哈希清单。
- [~] 旧功能回归细节继续根据试用反馈修整。本次不宣称旧 85 项脚本全部通过。

## 可以这样试

1. 开始对话，选择一个已有知识库，问“这些资料里最值得先学什么”。
2. 说“根据这些资料，为我生成一份实操指南”，观察实际工具调用，右侧打开成果。
3. 说“围绕同一主题出四道分阶测试”，直接在右侧作答。
4. 说“记住，我喜欢先看具体例子再讲概念”，到学习记忆中查看来源、更正或忘记。
5. 打开一份成果，点“让 Agent 修改”，填写要求；生成新版后切换版本、查看差异。
6. 生成四页在线演示，点击开始演示，用方向键翻页，关闭后重新打开检查续播。

## 验证边界

- 已完成 57 项隔离 HTTP/浏览器工作台检查；停止专项曾通过 11 项检查，随后补充了“正文尚未返回时取消”的终态修复。
- 真实模型在本机数据库副本中跑通：四题测验 → 服务端判错 → 带更新证据的实操 → 四页演示 → 讲义 → 实操第二版 → 遗忘记忆。未修改本人真实学习数据来做测试。
- 旧 UI 全量回归最后一轮为 78/85；包含旧预览/文件名假设、异步列表断言及停止/审批场景。部分已调整或修复，按用户要求不继续扩展全量回归后再交付。
- 本版为试用交付。生成质量与速度仍受所配置模型影响；演示支持在线播放，尚不承诺 PowerPoint 文件导出。掌握度证据有限时保持未知。
