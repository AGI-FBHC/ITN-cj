## 二、联网检索与技能（来自 `09-联网检索与技能设计.md`）

按文档的落地顺序推进，**一个阶段一个提交**，每阶段独立可验证。

| 阶段 | 内容 | 状态 | 验收方式 |
| --- | --- | --- | --- |
| P1 | `web_fetch(url)`：贴链接就能读 → 落本机 `webcache` → 以 `[W1]` 引用；设置页「联网」总开关 + 域名黑白名单 | [ ] | 本地起 mini HTTP 服务当"网页"；抓取→正文入库→回答带 `[W1]`→资源页可见→可删 |
| P2 | `web_search` provider 适配器（tavily/brave/searxng/custom，都不内置 Key）+「测试搜索」+ 候选勾选剔除 | [~] | Tavily 已通（见 R10）；待补 brave/searxng/custom 与候选卡片 |
| P3 | 欠缺判定四信号 +「资料不足」卡片 + 三级授权（一次/会话/永久）+ 计划行可停；引用自检区分 `[n]`/`[Wn]` | [ ] | 提一个 KB 里没有的问题；断言卡片出现、"只用手头资料"走原路径、"上网查"才发请求、联网中可停 |
| P4 | Skills：目录扫描 + 清单入提示 + `skill_read` + `/` 选择 + 设置页「技能」卡片 + 内置 `web-research` | [ ] | fixture 技能能被列出/被读取/**越权工具被拒**；用 `web-research` 跑通"查→抓→答→落" |

已按文档第六节采纳的默认值：默认**不自动**联网；provider 都不内置 Key；抓回内容默认只进 `webcache` 不入索引；skill 第一版**不允许脚本**；只有"并入知识库"之后联网内容才参与向量化。
