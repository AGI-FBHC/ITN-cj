# 技术验证记录

三项会卡住方案的前提全部验证通过。以下都是本机实测结果，不是推断。

## 工具链

| 项目 | 版本 / 位置 |
| --- | --- |
| 仓颉 SDK | 1.2.0（cjnative），目标 `x86_64-w64-mingw32`，解压于 `D:\cangjie-sdk\1.2.0\cangjie` |
| STDX | 1.2.0.1 for windows_x86_64_cjnative，静态库位于 `D:\cangjie-sdk\1.2.0\stdx\windows_x86_64_cjnative\static\stdx` |
| OpenSSL | 3.6.5（取自 MSYS2 mingw-w64-x86_64-openssl 包），位于 `D:\cangjie-sdk\1.2.0\openssl\mingw64` |
| 编译器前置 | Visual Studio 生成工具 2022（MSVC 14.44.35207）+ Windows SDK 10.0.26100 |

SDK 官方下载页是单页应用，`preDownLoad` 只是登录校验接口；真实地址形如
`/v1/files/auth/downLoad?nsId=142267&fileName=<包名>&objectKey=<对象键>`，
其中对象键和 SHA256 都在下载页的 JS chunk 数据里。两个安装包均已按官网 SHA256 校验。

## 关键链接参数

```text
-lssl -lcrypto -lcangjie-dynamicLoader-opensslFFI -lcrypt32
```

`-lcrypt32` 不能省。stdx 的 `crypto.x509` 会调用 Windows 证书 API，缺它会出现
`CertEnumCertificatesInStore`、`CertCloseStore` 等未定义符号。

stdx 通过 `cjpm.toml` 的 `bin-dependencies.path-option` 引入，值用环境变量
`${CANGJIE_STDX_PATH}`，由 `scripts/env.ps1` 设置。链接期把 OpenSSL 的 lib 目录放进
`LIBRARY_PATH`，运行期把 OpenSSL 的 bin 目录放进 `PATH`。

## 验证一：本地 HTTP 服务

`ServerBuilder().addr("127.0.0.1").port(0).build()` 由系统分配端口，实测拿到 52161 等随机端口。
`/health` 返回 200 与预期 JSON，未注册路径返回 404。

## 验证二：HTTPS 出网

`stdx.net.http` 配合 `stdx.net.tls` 的 `TlsClientConfig` 实测：

| 目标 | 结果 |
| --- | --- |
| `https://cangjie-lang.cn/`（显式 ALPN http/1.1） | 200 |
| `https://cangjie-lang.cn/`（默认配置） | 200 |
| `https://www.baidu.com/` | 200 |
| `https://www.example.com/` | 握手失败 |

最后一项是本机代理链路的拦截，与本项目代码无关；`TlsClientConfig` 默认配置即可用，不必显式设置 ALPN。

## 验证三：目标机器无需安装仓颉

把可执行文件复制到空目录，用 `PATH` 只含 `C:\Windows\System32;C:\Windows` 的干净环境启动，HTTP 与 HTTPS 均正常。

最小依赖集共约 17MB：

| 文件 | 大小 |
| --- | --- |
| `itn-desktop-core.exe` | 9.55 MB |
| `libcangjie-runtime.dll` | 1.24 MB |
| `libboundscheck.dll` | 0.04 MB |
| `libssl-3-x64.dll` | 0.95 MB |
| `libcrypto-3-x64.dll` | 5.25 MB |

可执行文件只动态依赖 `libcangjie-runtime.dll`，标准库与 stdx 都是静态链入；
OpenSSL 由 `libcangjie-dynamicLoader-opensslFFI` 在运行时动态加载，所以 `libssl` / `libcrypto` 必须随包分发。

## 已知问题

`println` 输出到管道时会被缓冲，进程不退出就看不到端口号。Electron 的端口握手不能依赖标准输出，
后续改为内核把端口写入外壳指定的文件，或找到显式 flush 的方式。
