# ITN

ITN（Intelligent Training Nexus）是面向个性化学习与智能教培的应用，提供网页版学习平台和本地桌面工作台，帮助你学习知识、整理资料、提问、练习与复习。

本仓库是基于仓颉开发的 ITN 新版本，延续[原 ITN 项目](https://github.com/AGI-FBHC/ITN)的学习与训练方向。目前提供 **Web 网页版**和 **Desktop 桌面版（Lumin）**两种使用方式。

## 选择适合你的版本

| | Web 网页版 | Desktop 桌面版 |
| --- | --- | --- |
| 怎么使用 | 打开浏览器访问平台 | 在 Windows 电脑上运行应用 |
| 适合什么场景 | 在线学习、课程练习与教学训练 | 使用个人资料学习、问答和生成学习材料 |
| 是否需要配置模型 | 由平台提供和配置 | 使用你自己配置的模型服务 |
| 资料与记录放在哪里 | 所使用的平台中 | 本机数据目录中 |

## Web 网页版

通过网页版，你可以查看课程和知识网络，按知识点学习与练习，记录笔记、整理错题，并查看学习画像与成长记录。

**[进入网页版体验](http://43.160.236.121:20889/)**

1. 打开平台，登录账号，或选择登录页上的“游客体验”。
2. 进入学习页面，选择课程或知识点，阅读内容并完成练习。
3. 在笔记、错题本和成长页面中继续整理、复习和查看学习记录。

当前链接为体验环境。

## Desktop 桌面版 · Lumin

桌面版适合围绕自己的资料学习。你可以把文件或文件夹整理成知识库，与 AI 对话、检索原文，生成讲义和练习，并在工作台中阅读、查看和继续修改学习材料。

桌面版还提供笔记、错题与学习记录，方便把资料阅读、问答和复习连在一起使用。

### 使用方式

桌面版面向 Windows 10 / 11 的64位电脑。本仓库目前尚未发布桌面应用下载包。

拿到桌面应用包后：

1. 解压应用包，运行 `Lumin.exe`。
2. 打开“设置”，填写所使用模型服务的接口地址、密钥和模型名称，测试连接后保存。
3. 导入自己的资料或选择资料目录，建立知识库。
4. 在工作台中描述学习目标，开始提问、生成材料或练习。

## 资料与数据

网页版的学习记录由所使用的平台保存。桌面版的知识库、会话、学习记录和产物保存在本机数据目录中。

桌面版调用远程模型或联网工具时，会把任务所需的资料片段、问题或链接发送给相应服务。使用前请确认模型服务和资料范围适合自己的需求。
