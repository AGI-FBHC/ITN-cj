# ITN-Desktop 使用说明

## 0.2.0 个人学习 Agent 试用版

解压运行 ITN-Desktop.exe，默认进入 Agent 工作台。描述学习任务，由 lumin 按需调用讲义、实操、分阶测试或在线演示工具；成果在右侧阅读、作答、播放和修改。学习中心保留旧功能，学习记忆支持更正、遗忘和关闭自动积累。完整使用步骤与边界见仓库 docs/14-个人学习Agent试用版交付.md。


## 这是什么

一个在你电脑上本地运行的教培内容工作台。你把自己手头的资料（Markdown、纯文本，含图片的也能读）交给它，再配上你自己的模型接口，它就能：

- 就你的资料回答问题，**每个结论都标出处编号**；
- 把一章内容生成**讲义**（先拟大纲，再逐节写作，最后跑一次引用自检）；
- 生成**分层练习题**与**交互式单选题**；
- 在对话里自己调用本地工具（检索资料、按 id 取原文、算数、看时间、写笔记、写产物）。

不需要注册、不需要登录，资料只发给你自己配置的模型服务。

## 运行环境

Windows 10 / 11，64 位。

**不需要安装仓颉，也不需要安装 Node。** 解压后直接运行即可。

## 界面长什么样

窗口用的是**自绘标题栏**（不是 Windows 原生那条）：顶部深绿色一条是应用的框，左边是应用名，右边是最小化 / 最大化 / 关闭；双击标题栏即可最大化或还原。侧栏顶部那个「检索资料与笔记」按钮（快捷键 `Ctrl + K`）可以一次搜遍**资料切片、章节、笔记、产物**，也可以直接在那里发起提问或生成讲义。

左边是8个功能入口：首页、学 · 练、我的成长、我的资源、个性化资源、领域知识库、伴学助手、设置。
进入「伴学助手」后会显示按知识库分组的会话栏，右边是主对话框。新建时先选资料范围：某个知识库，或可访问全部本机知识库的通用模式。

普通问答和讲义/练习生成共用 lumin 运行时。模型按任务选择是否检索、是否使用工具以及调用次序。
输入区只保留 ＋、权限档位和发送；生成期间可停止或输入新要求插话。输入 `/` 可选择技能。
联网搜索或网页读取期间也可停止。点击后先显示“正在停止”，收到任务终态后恢复发送；
切换会话不会改变停止按钮针对的实际运行任务。等待区会显示真实工具或模型活动，而非一直笼统显示“思考中”。
工具记录按实际发生顺序显示，点击展开细节；指定工作目录后可以使用本机文件工具，越界写入、命令与联网按权限档位审批。

## 收集网页与仓库资料

1. 打开「领域知识库 → 收集资料」，也可从「我的资源 → 网络资料」进入。
2. 粘贴网页链接，或选择 GitHub 仓库并填 `owner/repo`（分支/tag可选）。点「抓取到暂存区」。
3. 查看来源、抓取时间、完整commit与文件清单，点文件名预览正文。
4. 选择目标知识库，勾选「我已检查清单与来源」，点「确认并入并建索引」。未确认前资料不会进入检索。
5. 不需要的待确认来源可点「不并入」。重新抓取会产生一份新的待确认快照，不覆盖已并入版本。

也可以在伴学助手输入 `/kb-harvest` 请 lumin 收集；它能抓取并暂存，最终仍需用户在界面确认。
GitHub 暂支持公开仓库的文本资料，上限300文件、单文件4MB、合计32MB；图片与构建目录跳过。
遇到网络错误或 GitHub 限流会显示实际失败原因，本轮不会假装抓取成功。

## 阅读、播放与记录

- 消息流里的每一条灰色横条都是一次真实的工具调用（例如「检索知识库 · 命中 6 个切片」）。
- 回答生成过程中会**流式显示**文字；生成期间窗口不会卡住，可以切到别的页面看。
- **随时可以停**：想错了主题或问题写歪了，点「停止」（对话里在输入框旁，生成讲义/练习册时在进度卡上）。
  停下来会告诉你停在哪一步；讲义这种多步生成**不会保存半成品**，并会给出「重新生成 / 重新问一次」的入口。
- 会话栏里的对话按知识库分组，通用模式单独一组，组头可以折叠；
  点开旧会话会自动把当前知识库切回它自己那个，然后还原当时的对话与出处。
- 在对话页换知识库 = 换一套资料，会自动开一段新会话（旧会话留在会话栏里，随时能回去）。
- **按页播放**：在「个性化资源」打开讲义/练习册的「播放」，或在「学 · 练」按节播放整章。支持上下页、目录、字号、全屏与键盘翻页；上次播放位置保存在本机。
- **画像校准**：在「我的成长」就地展开。六维能力各选一个档位，并与真实学习记录对照；结果保存到本机档案，可选生成一条校准笔记。

## 快速开始

1. 解压本压缩包到任意目录（不要在压缩包里直接运行）。
2. 双击 `ITN-Desktop.exe`。窗口左下角显示「内核已连接」即表示就绪。
3. 首页「开始使用」有一张五步清单，每一步都能直接点过去；走完这五步就能出讲义了。
4. **配模型**（「设置 → 模型与接口」）：点预设按钮填入地址与模型名，再补 API Key。
   - `MiMo TokenPlan · v2.6 flash`：`https://token-plan-cn.xiaomimimo.com/v1`，对话模型 `mimo-v2.6-flash`，多模态 `mimo-v2.6-pro`。日常问答用它，便宜且快。
   - `MiMo TokenPlan · v2.6 pro`：全部用 `mimo-v2.6-pro`，理解更稳、讲义更完整，单次耗时也更长。
   - `DeepSeek` / `其它 OpenAI 兼容服务`：任何兼容 `/chat/completions` 的服务都能用。
   - 保存后点该行的「测试连通」，显示「连通 ✓」即配置正确。
   - 用途可以分开绑：`对话与生成`（问答、讲义、练习）、`向量检索`（可选）、`切片与图片描述`（多模态）。
5. **配知识库**（「设置 → 知识库」）：导入文件或文件夹，或填写资料目录后保存并建立索引。
6. **开始用**：
   - 对话：在「伴学助手」里直接提问。想让它算数、看有哪些文档、查时间，直接说就行——它会自己调工具。
   - 讲义 / 练习册：在「学 · 练」选一章生成，或在对话的 ＋ 菜单中发起。生成卡按真实发生顺序显示工具调用和正文，没有固定的大纲/逐节流程。
    生成的 Markdown 在「个性化资源」里可读全文、按页播放、搜索、重命名和删除；也可直接用其他编辑器打开。
   - 自测：在「学 · 练」点「出题练习」做单选，答错的会进「错题本」。
  - **错题本按间隔复习安排**：页面顶部直接告诉你「今天该复习 N 条」。重做一道题时会**给出和当初一样的选项**
    （不是让你对着答案自评）；答对往后推（1 → 3 → 7 → 16 → 35 天），答错就回到今天；特别熟的可以「标记已掌握」。
    早期记录（那时还没存下选项）会退化成"对着参考答案自评"，页面会说明原因。
7. **看过程**（「会话记录」页）：每条会话都能展开成事件序列——检索了几次、调用了什么工具、模型调用了几轮、引用自检的结果。这是「答案可溯源、产物可复现」的落地方式。

## 数据放在哪

默认在 `%LOCALAPPDATA%\ITN-Desktop`，全部数据都在**一个 SQLite 文件**里（`itn.db`），可以整体拷走或备份。

| 位置 | 内容 |
| --- | --- |
| `itn.db` | 模型配置（含密钥，只在本机）、知识库登记、切片、向量、学习进度、笔记、错题、会话事件 |
| `artifacts\` | 生成的讲义与练习册，Markdown 格式 |
| `sessions\`（历史遗留） | 早期版本的 JSONL 会话日志，迁移后保留为 `*.migrated` |

## 备份与恢复

数据都在本机一个 SQLite 文件里（`数据目录\itn.db`），「档案与知识库」页最下面有「数据与备份」：

- 点「立即备份」会把整个数据库复制到 `数据目录\backups\itn-<日期>-<时间>.db`，
  并且**立刻把副本当数据库打开校验一次**——拷出来打不开的备份不算备份（校验失败会删掉副本让你重试）。
- 备份列表里能看到每份备份的大小，可以复制路径或删掉（删的只是副本，不影响当前数据）。
- 恢复方式：先退出应用，把备份文件改名成 `itn.db` 覆盖数据目录里的同名文件
  （若旁边还有 `itn.db-journal`，一并删掉），再启动即可。

## 常见问题

**点「测试连通」失败。** 检查 Base URL 是否以 `/v1` 结尾、密钥是否正确。模型行上还有「诊断连接」，会逐个尝试常见的 TLS 协商参数并报告哪一种可用。

**我的资料是 PDF / Word，读不进来。** 桌面版能读的是 Markdown、纯文本、CSV、HTML、日志、JSON（纯仓颉里没有解析 PDF/Word/PPT 的依赖）。
建立索引后如果目录里有读不了的文件，界面会**明确告诉你**「未纳入 N 个文件：pdf ×3、docx ×1」，不会静默跳过；
「领域知识库」页也能随时回看这份提示。解决办法：把资料另存为 Markdown 或文本再放进来。

**建立索引时提示服务没有 `/embeddings`。** 很多服务只提供对话接口（例如 MiMo TokenPlan）。这时把「向量检索」留空即可——知识库会自动退回**关键词检索**，功能不受影响；想要向量检索，单独绑一个带 `/embeddings` 的服务。

**图片没有被理解。** 需要把「切片与图片描述」绑定到一个**多模态**模型（例如 `mimo-v2.6-pro`），否则只按正文文本切片。

**回答里没有出处编号。** 说明检索没命中，或对话模型没按要求标注。先确认知识库已建立索引（「领域知识库」页有统计），再换一个更贴近资料原文的问法。

**生成讲义很慢。** lumin 按任务选择工具，可能多次请求模型；时间线会显示实际进展。可以随时停止。模型连续90秒没有返回数据时会报失败，不再一直等待。

**资料会上传到别处吗。** 提问、索引与生成所需的资料片段会发给你配置的模型服务；开启联网时搜索词和指定链接也会发给相应服务。资料库、来源快照和学习记录保存在本机。
