学习资料不再散落在不同窗口

从资料导入到课件生成，从课堂提问到知识复习，Lumin 把同一份学习内容贯穿到每个操作里。

概念回到它们的关系里

课件和问题留在同一页

打开真实 PPT 后，右侧会话会带着当前页和知识库上下文开始。每个导学会话仍是普通对话，可以继续、切换，也可以新建。

桌面版使用用户配置的模型接口。知识库、学习记录、笔记和模型密钥保存在本机；切换服务商不需要迁移已有资料。

{{INSTALL_INSTRUCTIONS}}

系统

Windows 10 1903 或更新版本、Windows 11，64 位系统。可使用安装版，或选择 ZIP 便携版。

模型

在设置中填写兼容接口、密钥和模型名称。密钥仅写入本机数据库。

数据

知识库、对话、学习档案和笔记保存在当前 Windows 用户目录。

安装前确认

按所选版本安装或解压，然后配置自己的模型服务。

安装版和便携版有什么区别？

安装版运行 EXE 后按提示安装，提供开始菜单入口和卸载功能；便携版解压后运行 Lumin.exe。两种版本功能相同。

需要单独安装仓颉吗？

不需要。两个版本均已包含应用运行所需的仓颉业务内核。

首次启动要配置什么？

打开“设置 → 模型与接口”，填写接口地址、密钥和模型名称。保存后即可开始对话、生成学习资源或随课导学。

学习数据保存在云端吗？

桌面版的知识库、学习记录、笔记和模型密钥保存在本机。调用外部模型时，请求内容仍会发送到你配置的模型服务。
