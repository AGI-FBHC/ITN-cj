# 联网专题研究

目标：**先用手头的资料，缺什么才上网补什么**，最后给出一份每条结论都能追到出处的材料。

## 步骤

1. **先查本机**：用 `kb_search` 搜一遍主题。命中就用，命中的切片在结论里写成 `[编号]`。
2. **说清缺口**：本机资料没有覆盖的那部分，明确讲出来（哪一块资料里没有），再去联网。
3. **找候选**：用 `web_search` 搜 2-5 条候选（标题 + 链接 + 摘要）。不要在正文里整段抄摘要，正文只写结论。
4. **逐篇读正文**：挑 2-4 个最相关的链接，用 `web_fetch` 把正文抓下来（会自动落到本机 webcache，可审计可删）。抓不到就如实说"这条读不了"，换一条，别编。
5. **写结论**：本机资料用 `[1]`、`[2]`；网页用 `[W1]`、`[W2]` **单独编号**，并在句子后面写出链接（网页会变，所以还要带上抓取时间）。
6. **留痕或交付**：
   - 只想留个记录：`save_note` 写一条笔记。
   - 要给别人看：`save_artifact` 写成 Markdown（例如 `专题-<主题>.md`），末尾附一段"资料来源"列出本机资料与网页链接。

## 几条底线

- 本机资料与网页冲突时，**以本机资料为准**，并把冲突讲出来。
- 抓不到、搜不到，就说"没找到"，不要用看起来合理的说法凑一段。
- 不递归爬站、不整站镜像：只读你挑中的那几篇。
- 引用编号不要串台：`[n]` 是本机资料、`[Wn]` 是网页。
