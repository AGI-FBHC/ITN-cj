# core —— 仓颉内核

项目主体。计划中的模块：

| 模块 | 职责 |
| --- | --- |
| `kb` | 扫描目录、Markdown 结构分块、图片抽取与多模态描述 |
| `index` | 向量索引的建立、存储与检索 |
| `model` | OpenAI 兼容的文本、视觉、向量三类调用 |
| `agent` | ReAct 循环、工具注册、会话记忆 |
| `store` | 本地文件存储：配置、索引、会话、产物 |
| `api` | 对内暴露的本地 HTTP 接口 |
